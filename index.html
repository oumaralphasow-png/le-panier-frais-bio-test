Checklist automatique

Actions avant mise en ligne

1. PostgreSQL persistant
La base de production ne doit pas reposer sur un fichier SQLite éphémère.
2. Secrets & comptes
Changer la clé secrète, désactiver les comptes démo et créer les vrais comptes équipe.
3. Données métier
Valider fiscalité, coûts, fournisseurs, produits, lots et règles opérationnelles.
4. Sauvegarde
Exporter un instantané complet avant le basculement.
5. Test du parcours complet
Commande → stock → production → livraison/retrait → facture → paiement.

Test fonctionnel à blanc

Le test crée temporairement un client, une commande, une facture, un paiement, une production et une réception fournisseur dans une transaction, puis annule toutes les écritures par rollback.

Fichiers de déploiement

Le pack V62 contient aussi un modèle render.production.yaml séparé du fichier de test actuel. Il est prévu pour le passage final à PostgreSQL + secret généré, sans toucher au déploiement de test avant validation.
